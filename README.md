# 하루의 조각 · V16 (사용자가 선택한 조각이 디자인)

이 파일은 기존 `pyo-yj/daypiece` 저장소의 앱을 **업데이트**하는 통합본입니다. 새 저장소를 만들지 마세요.

## 이번 변경

- 이전에 골랐던 동글동글한 크림색 고양이와 체크 쿠션 그림을 그대로 사용했습니다. 억지로 누끼를 따지 않고 원본의 포근한 배경을 살렸습니다.
- 오늘: 그림 속 고양이를 누르면 조각이 방으로 이동. 레벨, 목표, 일기, 감사한 일 세 가지, 식사/루틴 바로가기가 한 화면에 표시됩니다.
- 오늘의 목표/일기/감사 카드: 누르면 편집 화면으로 이동. 자동 저장, 목표 완료 체크 가능.
- 조각이 방: 앨범/아이템/편지/도감 탭을 누르면 해당 콘텐츠가 열립니다. 기존 레벨·아이템·편지 데이터가 유지됩니다.
- 음식 73종 및 기존 식사 기록 기능을 유지하고, 누락됐던 계란말이/순두부찌개/부대찌개 그림 연결을 바로잡았습니다.
- 기존 날짜별 기록, 기분 18종, 루틴과 단어, 캘린더, 월간 회고, Firebase 동기화 설정을 유지했습니다.
- 홈 화면의 핑크 발바닥 아이콘과 하루 종일 밝은 테마를 유지했습니다. 유료 서비스나 AI API는 추가하지 않았습니다.

## GitHub 업로드 · 컴퓨터에서

1. **중요:** 아이폰/컴퓨터 앱에서 `설정 → 데이터 백업 → 백업 파일 저장`을 먼저 실행하세요. 앱을 삭제하거나 GitHub 저장소를 지우지 마세요.
2. ZIP을 다운로드하고 **압축을 풀어**, 이 README.md 파일과 나머지 파일들이 보이는 폴더를 여세요.
3. https://github.com/pyo-yj/daypiece/ 에 접속해 `Code → Add file → Upload files`를 선택하세요.
4. **압축 푼 폴더 안에 있는 파일 전체 17개**를 선택해서 업로드 창으로 끌어다 놓으세요. **ZIP 파일을 그대로 올리는 것이 아닙니다.**
5. 업로드 목록에 `jogaki-cat.webp`와 `jogaki-room.webp`가 모두 있는지 확인하세요. 나머지 기존 파일도 정상 등록됐으면 아래 `Commit changes`를 누르세요.
6. 배포 후 https://pyo-yj.github.io/daypiece/ 에서 확인하세요. 기존 화면이 계속 뜨면 앱을 종료하고 다시 열거나 Safari에서 새로고침하세요. 캐시 때문에 업데이트 반영까지 시간이 걸릴 수 있습니다.

## 기존 기록 및 동기화 주의

- 기존 저장 키 `daypiece_v2`와 Firebase Firestore 데이터 구조는 변경하지 않았습니다.
- 기존 기록과 Firebase 연결 설정을 **지우지 않도록** 업데이트를 만들었지만, 모든 기기의 실제 동기화 상황을 확인할 수는 없습니다. 백업은 꼭 먼저 해 주세요.
- 앱 설치를 위해 iPhone 홈 화면 앱을 삭제하는 것은 **백업 확인 전에는 하지 마세요.**
- Firebase Spark 무료 요금제를 유지하며 유료 Blaze 업그레이드, 결제 정보, 유료 OpenAI API가 필요하지 않습니다.
- GitHub에 업로드하는 소스에는 개인 로그인 비밀번호나 Firebase 개인 기록을 추가하지 마세요.

## 검사

- 브라우저에서 아이폰 크기 화면 표시, 조각이 방의 네 탭, 목표 체크, 일기/감사 3개 자동 저장, 식사 73종 이미지 표시, 루틴·단어, 설정 화면과 창 너비 넘침 등을 검사했습니다.
- 실제 아이폰에서 GitHub 배포본의 Firebase 로그인·실시간 동기화까지 완전한 실기기 검사는 하지 않았습니다.
