# 하루의 조각 · Daypiece

아이폰 15와 PC에서 쓰기 위한 개인용 루틴·일상 수집 PWA. **추가 비용 없는 구현을 최우선**으로 합니다.

## 실행

- `index.html`을 브라우저에서 열면 로컬 저장으로 즉시 사용할 수 있습니다.
- iPhone 홈 화면 설치 및 오프라인 캐시는 HTTPS 웹 서버에 배포해야 작동합니다.
- `설치안내.html`을 브라우저에서 열면 무료 GitHub Pages 배포 및 선택형 Firebase Spark 동기화 설정 방법이 있습니다.
- 테스트용 로컬 서버: `python -m http.server 8000` 후 `http://localhost:8000`에 접속합니다.

## 포함 기능

- 시간에 따른 테마: 07:00~19:59 미니멀, 20:00~06:59 다크
- 요일별 루틴, 일일 체크, 메모, 기분, 식사 기록
- 달력, 주간 달성률, 월간 회고
- 미리 작성한 비밀편지 및 영·일 단어
- 캐릭터 경험치, 아이템, 컬렉션
- 무료 비상업용 Open-Meteo 날씨
- 기기 내 데이터 보관, JSON 백업, 선택형 Firebase Spark 동기화

## 비용 및 한계

- 유료 AI API 사용하지 않음. 매일 AI가 자동으로 새 글을 생성하는 기능 없음.
- Firebase는 **사용자가 직접 만든 Spark(무료) 프로젝트를 연결할 때만** 활성화. 유료 Blaze 전환 금지.
- **아이폰 백그라운드 푸시 발송 미구현**. 별도 발송 서버 구성이 필요.
- 로컬 데이터는 기기별로 따로 저장됨. 설정에서 Firebase 무료 계정을 연동하거나 백업 파일을 옮겨야 동기화 가능.
- 사용자가 준 ChatGPT 공유 링크는 본문 확인 실패로 반영 여부를 확인하지 못함.

## 데이터 정책

백업 파일에는 일기, 식사, 기분, 루틴 등 개인 데이터가 들어 있습니다. 공개 저장소에 백업 파일을 업로드하지 마세요.
